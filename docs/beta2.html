Opções retornar top 3
Modo estrito ativo = retorna somente o melhor trecho. Desligado = retorna até 3 trechos.
Como usar
1) Cole seu texto base. 2) Clique em Salvar texto. 3) Faça perguntas no campo abaixo. O app encontra trechos que compartilham ao menos uma palavra (ignorando acentos, caixa e palavras muito comuns) e destaca as coincidências.
Pronto para GitHub Pages: 1 arquivo HTML, sem backend e sem bibliotecas externas.
